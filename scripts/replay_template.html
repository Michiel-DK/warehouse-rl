What you are watching. The request queue holds 20 shelves at a time (orange). FIFO sends the closest idle AGV to the first requested shelf and a picker to meet it there. The AGV then drives the shelf to a workstation, returns it to any empty slot, and becomes idle again.

Faint lines are each agent's current target. Agents stepping into each other recompute their path, which is where the clash count comes from.

This is the baseline the RL policy has to beat. The RL agent replaces the "which shelf, which workstation, which slot" decisions. The driving stays A*.
